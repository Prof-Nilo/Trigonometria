# Trigonometria
O **Desafio do Ciclo Trigonométrico** é um jogo web educacional com visual rústico que apresenta rodadas de 10 perguntas sobre ângulos, quadrantes e radianos. Ele destaca o seno e o cosseno visualmente em um ciclo dinâmico e traz um sistema de penalidade: ao errar 3 vezes, o aluno vê a resolução explicada e digita a resposta para avançar.
